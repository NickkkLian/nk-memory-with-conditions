# Memory file template

```markdown
---
name: <short-kebab-slug>
description: <one line used to decide whether this memory is relevant>
type: user | feedback | project | reference
---

<the fact, in one or two sentences>

**Holds when:** <conditions: which tool, which version, which environment, which sample; the date>

**Why:** <the incident or the instruction, dated; quote the person if it was an instruction>

**How to apply:** <the checkable action next time; link related memories with [[their-slug]]>
```

Index line in `MEMORY.md`: `- [Title](file.md) — <hook: one clause, no summary>`

Never put the memory's content in the index; the index is a table of contents with a size cap.
